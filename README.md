# 🚀 AstroScrap

# 

# A 3D Zero-G space survival sandbox built in Unreal Engine 5, featuring realistic Newtonian gravitational fields, modular interaction systems, and floating debris scavenging.

# 

# 📖 Overview

# 

# AstroScrap puts players in the shoes of a stranded space scavenger trapped in an asteroid belt where global gravity is non-existent ($Z = 0$). To survive, players must master inertial navigation in Zero-G, manipulate physics-enabled debris, harvest asteroids, and build a pressurized home in deep space.

# 

# Unlike conventional space games, gravity in AstroScrap is entirely local and generated dynamically by the mass of celestial bodies based on realistic Newtonian principles.

# 

# ✨ Key Features

# 

# 🌌 Zero-G \& Newtonian Physics System:

# 

# Global gravity disabled ($Z = 0$).

# 

# Dynamic local gravity fields generated by asteroids ($F = G \\frac{M\_1 M\_2}{d^2}$).

# 

# Pure Blueprint function CalculateGravityForce with safety clamping and accurate acceleration handling.

# 

# 👩‍🚀 Flying Movement Mechanics:

# 

# Custom Zero-G character navigation powered by CharacterMovementComponent in Flying mode.

# 

# Frictionless inertia with adjustable deceleration parameters for realistic drifting.

# 

# 🧲 Modular Interaction System (Grab / Hold / Throw):

# 

# Decoupled architecture using Blueprint Interfaces (BPI\_Interactable) to eliminate heavy casting.

# 

# Real-time raycasting (LineTraceByChannel) for target acquisition.

# 

# Time-weighted charged throw mechanics with dynamic impulse expulsion.

# 

# 🎯 Radial Charge HUD \& Debug Instrumentation:

# 

# Custom radial charge gauge with symmetric arc filling.

# 

# Real-time on-screen telemetry tracking force vectors, captured target names, and gravitational influence events.

#
